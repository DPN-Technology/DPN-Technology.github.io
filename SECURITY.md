# Security Policy

DPN Technology handles security issues privately.

Do not open a public issue for a vulnerability that could expose credentials, sensitive data, authorization weaknesses, infrastructure details, or exploitable behavior.

Use GitHub private vulnerability reporting when it is available for this repository. Include the affected version or commit, impact, safe reproduction details, and relevant evidence with live credentials removed.

The organization-level policy in `DPN-Technology/.github` defines the default DPN security reporting standard.
